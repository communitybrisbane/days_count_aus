## 2. キャッチコピー案

### メイン
- **Make Days Count** — ワーホリ365日で人生変える。
- **Your Working Holiday, Counted.** — 毎日を記録し、成長を可視化。

### サブ
- 渡航前のカウントダウンから、滞在中の毎日の記録まで。
- 5つのフォーカスモードで、自分だけのワーホリを記録しよう。
- 仲間と繋がり、刺激し合える。ワーホリ専用コミュニティ。

## 3. 主要機能（訴求ポイント）

### 3.1 日数カウント
- **渡航前**: D-30, D-29... カウントダウンでモチベUP
- **ワーホリ中**: D+1, D+2... 毎日の経過を実感
- **帰国後**: アプリ利用日数をカウントアップ
- ユーザーのローカル時間基準。フェーズはいつでも手動切替可能。

### 3.2 ジャーナル投稿
- 写真+テキスト（または テキストのみ）で日々の活動を記録（絵文字対応）
- **5つのフォーカスモード**: English / Skill / Challenge / Work / Chill
- ハッシュタグ（最大5個）+ 地域タグで整理
- テキストのみ投稿はモード別グラデーションカードで表示

### 3.3 XP・レベルシステム（ゲーミフィケーション）
- 投稿・いいねでXPを獲得、レベルアップ
- 連続投稿ストリーク（48時間ルール）
- 週間チャレンジ（週5日以上投稿で連続ボーナス）
- レベルに応じてグループ参加枠が増加

### 3.4 EXPLORE（タイムライン）
- 全ユーザーの公開投稿をスコアベースで表示
- フォロー中の投稿を優先表示
- モードフィルタ・ユーザー検索・タグ検索
- いいね（カンガルーアニメーション付き）

### 3.5 フォーカスグループ
- モード別の公式グループ + ユーザー作成グループ
- リアルタイムチャット（絵文字対応、参加/退出のシステムメッセージ付き）
- グループ終了後もチャット履歴を閲覧可能
- 最大12名の少人数制（Lv.2以上で参加・作成可能）
- 24時間 Study Room（常設Zoomリンク）

### 3.6 マイページ
- Instagram風プロフィール
- 投稿グリッド（4列）+ モードフィルタ
- Likes / Streak / Following の統計表示
- 所属グループ一覧

## 4. ユーザー体験フロー

```
1. days-count.com にアクセス
2. Googleログイン（ワンタップ）
3. オンボーディング（6ステップ）
   - ニックネーム + 写真
   - ステータス選択（Before / In AUS / Returned）
   - 渡航日設定
   - フォーカスモード選択
   - 地域選択（任意）
   - ゴール設定（任意）
4. HOME画面で日数カウント確認
5. 毎日の活動を投稿 → XP獲得 → レベルアップ
6. EXPLOREで他のワーホリ仲間の投稿を閲覧・いいね
7. グループで同じ目標の仲間とチャット
```

## 11. FAQ（LP掲載用）

**Q: 無料ですか？**
A: はい、完全無料です。

**Q: アプリのダウンロードは必要ですか？**
A: いいえ。ブラウザから days-count.com にアクセスするだけで使えます。ホーム画面に追加すればアプリのように使えます。

**Q: 英語が苦手でも使えますか？**
A: UI・投稿ともに英語のみですが、シンプルなUIなので直感的に操作できます。英語のアウトプット練習にもなります。

**Q: ワーホリ以外の人も使えますか？**
A: ワーホリ（オーストラリア）に特化した設計ですが、留学やワーケーションの方にもお使いいただけます。

**Q: データは安全ですか？**
A: Google認証 + Firebase のセキュリティ基盤を使用。投稿は公開/非公開を選べます。不適切な投稿は自動モデレーション + ユーザー通報で対応。
